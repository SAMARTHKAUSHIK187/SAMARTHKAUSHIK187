<summary><h3>🗜️ &nbsp; Huffman File Compressor &nbsp; <img src="https://img.shields.io/badge/C++-00599C?style=flat-square&logo=cplusplus&logoColor=white"/> <img src="https://img.shields.io/badge/Status-Complete-brightgreen?style=flat-square"/></h3></summary>

<br>

> **Lossless file compression & decompression using the Huffman Coding algorithm — built entirely in C++**

```
📦 Huffman-File-Compressor
 ├── 🌳 Huffman Tree Builder   → Greedy prefix tree with character frequency analysis
 ├── 📊 Data Structures        → Min-Priority Queue (Heap) + Unordered Hash Maps
 ├── ⚡ Complexity             → O(n log n) build time | O(1) code retrieval
 ├── 💾 Binary Streams         → Fast read/write for any file type
 └── 🔁 Serialization          → Tree embedded into compressed file for reconstruction
```

| Feature | Detail |
|:---|:---|
| 🧠 **Algorithm** | Greedy Huffman Tree — high-freq chars get shorter codes |
| 🏗️ **Core DS** | Min-Heap for tree construction, HashMap for O(1) lookups |
| 🚀 **Performance** | Minimized storage footprint with optimized bitwise encoding |
| 🔄 **Decompression** | Flawless data reconstruction via serialized tree |

</details>
